# Product Catalog API

A REST API built with FastAPI for managing a simple product catalog.

## Features

- Retrieve the API welcome message and version.
- List all products.
- Create products with request validation.
- Retrieve a product by ID.
- Update an existing product.
- Delete a product by ID.
- Return a `404 Not Found` response when a requested product does not exist.

## Technology Stack

- Python 3.12+
- FastAPI
- Pydantic
- Uvicorn
- uv for dependency and environment management

## Prerequisites

- Python 3.12 or later
- [uv](https://docs.astral.sh/uv/)

## Setup

Clone the repository:

```bash
git clone https://github.com/rishabh-git-hub/product-catalog-api.git
cd product-catalog-api
```

Synchronize the project environment using the committed lockfile:

```bash
uv sync --locked
```

## Run the API

```bash
uv run uvicorn main:app --reload
```

The local development server runs at `http://127.0.0.1:8000`.

## API Documentation

With the server running, open:

- Swagger UI: http://127.0.0.1:8000/docs
- ReDoc: http://127.0.0.1:8000/redoc
- Root endpoint: http://127.0.0.1:8000/

## Current Limitations

- Products are stored in memory and are not persisted across application restarts.
- Product IDs are generated by application code rather than a database.
- Automated test coverage has not yet been established.
- Authentication and authorization are not implemented.

## Development Status

This is a learning project being incrementally improved to demonstrate API development, testing, database integration, security, and deployment practices.
